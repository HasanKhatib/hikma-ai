# E3.2 - Public documentation

## Goal

Explain Hikma AI clearly to first-time users.

## Required Docs

- README quickstart.
- Installation guide.
- Command reference.
- Registry owner guide.
- Skill authoring guide.
- Troubleshooting guide for GitHub authentication and registry validation.

## Exit Check

README and docs cover install, init, registry setup, skill install, skill creation, and troubleshooting.

## Positioning (2026-10-09)

`gh skill` (GitHub CLI 2.90+) already installs, updates, searches, previews, publishes, and pins skills for 40+ agents, at project or user scope, with provenance in frontmatter. Plain "install a skill from a repo" is therefore a commodity. Hikma's pitch is the registry workflow: `init` for a whole repo (instruction files plus skills per agent, shared project config), a configured registry with a gated push by pull request (fork when needed), a lockfile with edit protection, and naming and validation policy. v0.2 items that duplicate `gh skill` (global scope, more agents) should be weighed against that.
