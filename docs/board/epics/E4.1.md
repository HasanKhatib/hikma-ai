# E4.1 - Complete skill lifecycle

## Goal

Fill the gaps around install and update so a repo's skills can be managed end to end. `sync` restores everything in `.hikma/lock.json` on a fresh clone.

## Trim (2026-10-10)

Keep `sync`, `remove`, and `list --installed` (the lockfile makes them cheap). `skill diff` was parked, then built after v0.2.0 as a read-only preview of an update (E4.1-T3).

## sync (2026-10-10)

Ships as `hikma sync`. The lockfile is untrusted input (it arrives with a clone), so sync fetches the recorded commit, verifies recorded hashes, validates every install path against the agent skill folders, and asks for confirmation (`--yes` in CI). The strict `--frozen` mode in E5.1 builds on this.
