# E6.1 - Stable contracts

## Goal

Freeze and document the surfaces that scripts and teams depend on before calling the CLI 1.0.

## Scopes (2026-10-12)

The lockfile schema, config keys (including `layouts`), and JSON output must be documented for both scopes: project (`.hikma/lock.json`) and global (`~/.hikma/lock.json`, E4.2). Global installs must land before v1.0 so these contracts are frozen once.
