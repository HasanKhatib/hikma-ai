# E3.1 - Build, test, and quality gates

## Goal

Establish confidence that the public CLI builds and behaves correctly.

## Scope

- Port existing tests only after the source import audit says they are safe and neutral.
- Add tests for registry configuration precedence.
- Add tests for Claude-first scaffold output.
- Add CI for formatting, tests, and builds.
- Add a final scan for private names, fixed registry URLs, and credentials before release.

## Exit Check

CI runs formatting, tests, and a build for every pull request.

## Review Addition

Cover `skill` and `registry` code with tests against a local fixture registry before v0.1.0.
