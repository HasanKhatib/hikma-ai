# E2.4 - CLI-only repository boundary

## Goal

Keep Hikma AI as only the CLI source repo, not a default or bundled skill registry.

## Context

The public CLI should be useful with any external registry. The first personal registry will be `hasankhatib/ai`, but the CLI repository itself should not own a top-level registry folder.

## Rules

- Do not add a top-level `skills/` folder to the Hikma AI repo.
- Use local fixture registry data only under explicit test fixture paths such as `internal/testdata/`.
- Make registry configuration explicit and visible to users.
- Use `hasankhatib/ai` in docs as an example, not a hidden fixed dependency.

## Exit Check

The repo has no top-level skills registry and tests prove the registry must come from config, flags, or user selection.
