# E1.1 - Claude-only project foundation

## Goal

Set up the repository so Claude can operate from one local roadmap board and one project instruction file.

## Context

This repository is the public home for Hikma AI. It should be Claude-first and should not add opencode configuration. The planning source of truth is `docs/board/`.

## Scope

- Add `CLAUDE.md` with project rules and agentkan workflow.
- Add `docs/board/` with roadmap state, next action, archive, viewer, and schema.
- Install the `agentkan` skill under `.claude/skills/agentkan` for project-local Claude discovery.
- Validate the board with `npx agentkan validate docs/board`.

## Exit Check

From the repo root, `npx agentkan validate docs/board` passes and Claude can find the board path and workflow from `CLAUDE.md`.
