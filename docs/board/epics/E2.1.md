# E2.1 - User-owned registry configuration

## Goal

Replace fixed registry assumptions with explicit user-owned registry configuration.

## Product Behavior

Users should be able to run Hikma AI against their own GitHub repository, organization repository, or local registry path. A default may exist for demos, but core commands must not require one fixed upstream.

## Design Questions

- Should registry config live in project files, user config, or both?
- Which value wins when a flag, environment variable, project config, and user config all exist?
- Should the registry support only GitHub URLs for MVP, or also local paths?
- What validation should run before commands touch a registry?

## Exit Check

The CLI can read, set, validate, and use a registry URL from project or user config.
