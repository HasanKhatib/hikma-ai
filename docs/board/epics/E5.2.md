# E5.2 - Signed releases

## Goal

Distribution is Homebrew plus an install script. Both should verify signatures or attestations. macOS notarization is a cost and account decision for the maintainer.

## Why notarization matters (2026-10-09)

The release binary is not notarized. A quarantined copy is killed by macOS (exit 137), so the Homebrew cask clears the quarantine flag in a `postflight` hook. Homebrew 7 warns that `postflight` is deprecated in favor of `postflight_steps`, but the new syntax breaks older Homebrew releases. Signing and notarizing the macOS binaries removes the need for the hook and the warning.
