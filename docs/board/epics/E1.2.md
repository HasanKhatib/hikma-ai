# E1.2 - Public identity and naming

## Goal

Lock the public identity around Hikma AI as the project name and `hikma` as the CLI command.

## Context

Hikma means wisdom. The product metaphor is a shared library of reusable AI-agent knowledge: instructions, skills, templates, and registry entries that users control.

## Decisions To Confirm

- Product name: Hikma AI.
- CLI name: `hikma`.
- Repository slug: `hikma-ai`.
- One-line description: repo-native CLI for scaffolding, sharing, and installing reusable AI-agent skills through user-owned registries.
- License: to be chosen before any broad public announcement.

## Exit Check

The README, command examples, release metadata, and package names consistently use Hikma AI and `hikma`.
