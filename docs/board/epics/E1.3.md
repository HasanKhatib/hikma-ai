# E1.3 - Source import audit

## Goal

Identify exactly what can be copied, renamed, generalized, or rewritten for the public tool.

## Context

The source CLI already has useful behavior, but the public project must be neutral. Before code is moved, audit all command names, package paths, templates, documentation, release files, URLs, and defaults.

## Audit Checklist

- CLI command tree and user-visible output.
- Go module path, binary name, package names, and import paths.
- Embedded scaffold and skill templates.
- Registry defaults and configuration behavior.
- GitHub authentication and preflight behavior.
- Release workflows, package formulas, install scripts, and generated artifacts.
- Test fixtures and golden files.
- README, docs, examples, and comments.

## Exit Check
