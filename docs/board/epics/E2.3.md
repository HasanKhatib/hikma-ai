# E2.3 - Skill lifecycle for public users

## Goal

Make skill list, install, create, update, and publish flows work with arbitrary registries.

## Product Behavior

Hikma AI should help users maintain their own reusable skill registry instead of relying on one centrally owned registry. The CLI should make the registry structure understandable and should fail loudly when a registry is missing required files.

## MVP Commands To Evaluate

- `hikma skill list`
- `hikma skill install <name>`
- `hikma skill create <name>`
- `hikma skill update <name>`
- `hikma registry get`
- `hikma registry set <url>`

## Exit Check

Skill lifecycle commands are documented, tested, and independent of any fixed registry owner.
