# E3.4 - Documentation site and pages

## Goal

Keep a public docs site option while allowing a Cloudflare Pages presence under `alkhatib.tech`.

## Context

GitHub Pages is useful for repository-native documentation and predictable open-source links. Cloudflare Pages can host the more polished public website under `alkhatib.tech`.

## Options

- GitHub Pages hosts the docs, and `alkhatib.tech` links to it.
- Cloudflare Pages hosts the main docs, and GitHub Pages redirects or mirrors content.
- GitHub Pages hosts command reference only, while Cloudflare Pages hosts marketing and guides.

## Exit Check

The repo can publish GitHub Pages docs and the docs content can also be deployed or linked from `alkhatib.tech`.

## Decision (2026-10-10)

GitHub Pages hosts the docs at https://hasankhatib.github.io/hikma-ai/, built with VitePress from `docs/site` (the earlier setup published raw Markdown and returned 404). One page per command, plus guides and use cases. Content must stay free of organization-specific references.
